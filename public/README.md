# Marmoris Static Assets

This folder contains static files and assets served at the root URL of your website.

## Using Your Official Logo PNG:
To use your official logo, please do the following:
1. Upload your logo PNG using the File Explorer in the top-left side of the AI Studio editor.
2. Rename the uploaded logo file exactly to `logo.png`.
3. Move or place it inside this `/public/` directory (so its path is `/public/logo.png`).

Once you place your `logo.png` here, both the **Header** and **Footer** of the website will automatically load and display your official logo beautifully! If the file is missing or fails to load, the system will automatically fall back to the elegant vector representation so the site never looks broken.
